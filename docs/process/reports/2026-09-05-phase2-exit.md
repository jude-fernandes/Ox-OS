# Phase 2 exit — virtual-target scope closed

Date: 2026-09-05
Status: **CLOSED for the virtual target.** Every in-scope deliverable is
gate-verified or explicitly hardware-deferred with a risk ID. The
hardware-measured exit criteria carry forward as fleet-side debt — none
are waved through.

## What the phase committed to (roadmap Phase 2)

> oxcom renders at panel refresh with atomic KMS; input incl. predictive
> touch; PipeWire audio; powerd (doze/wake budgets) + thermald + resourced
> (zram/PSI/OOM tiers); netpolicy per-app classes; dnsd; sensorhub.
> **Exit criteria**: zero dropped frames in scroll benchmark; input→photon
> ≤2 frames; standby ≤1%/h on fleet rig; suspend/resume 1000-cycle soak clean.

## Gate-verified on the virtual target

- **oxcom** — DRM/virtio-gpu scanout ownership, z-ordered clipped windows,
  keyboard + pointer routing (`key-recv`/`click-recv`), click-to-focus/raise,
  damage-tracked repaints (keystroke repaint 100% → 13.9% of frame).
- **input** — evdev read by the compositor, which owns all input routing
  (apps are pure IPC clients with zero evdev code).
- **audio** — PipeWire + WirePlumber session manager + eudev discovery; an
  ordinary unflagged app stream reaches a host wav capture.
- **powerd** — suspend/resume with RTC wake, idle-doze loop, wake locks;
  **1001-cycle soak, zero kernel errors, 4.7 h unattended** (the one exit
  criterion measurable in QEMU — clean).
- **thermald** — warn/hot/critical tiers with hysteresis (policy engine
  verified; QEMU has no thermal zones, so real trips are hardware work).
- **resourced** — zram swap tier sized + swapped under real pressure, PSI
  pressure tiers, protected OOM kill (tier-3 armed and unit-tested).
- **netd** — interface bring-up, DNS forwarder with pre-egress journaling,
  name policy with a refused canary proven never to reach the responder
  (covers the `dnsd` line; per-app socket enforcement remains netpolicy).
- **oxmodemd** — modem transport + AT engine + policy-gated SMS (host-side
  EG25-G emulator; no real radio exists in QEMU).
- **Phase-3 foundation landed early** — ox-ui toolkit (tokens → compositor
  ops, pixel-verified), ox-shell (lock screen, PIN auth, tap-to-launch),
  permstored (persistent grants, default deny, fail closed, persist-or-
  refuse), notifd (permission-checked posts + banner).
- **Build system** — hermetic Nix builds of the guest daemons AND the full
  image pipeline (pinned kernel → rootfs → verity → signed payload),
  deterministic store paths, boot-gate verified.
