# ox-ui — Phase 3 UI foundation (token layer + component library)

Date: 2026-09-05
Status: **DONE — UI GATE ALL GREEN** (token-correct home screen
pixel-verified; verdict at bottom)

## Scope

First Phase-3 chunk: the UI foundation everything else draws with.

`rust/crates/ox-ui` encodes the design language
(docs/design/design-language.md) as a token layer and compiles a
component tree into oxcom draw ops (`rect` / `text` JSON) — the
protocol oxcom already rasterizes with damage-tracked repaints.

- **Tokens**: palette roles (true-black OLED surface, Ox navy
  surface-high, Ox green primary, muted/outline/danger), 4 dp spacing
  grid, type scale (display/title/body/label; oxcom glyphs are
  8 px × scale), 48 dp minimum touch target.
- **Components**: `Screen` (full-bleed surface), `top_bar` (bar +
  primary accent + title), `card`, `button` (filled/outline/danger —
  refuses any height below the 48 dp touch target at build time),
  `tile` (home-grid app square), `label`.
- **Deterministic**: components are pure functions → ops; layout is
  unit-testable without a display (5 test cases incl. touch-target
  rejection, border-rect structure, text-inside-panel invariants).
- v0.1 geometry is flat (rects + text); rounded geometry arrives when
  oxcom grows a `rrect` op (next chunk — the design language's large
  radius identity needs it).

**First consumer**: ox-status now composes its screen through ox-ui —
top bar, status line, a 2×2 home-grid of app tiles (Settings / Files /
Terminal / Payments), an outline dock button, and the pointer-stack
card window. The toolkit is proven by the product's own first screen.

## Gate

`tools/ui-gate.sh`: boots with the display (OX_GFX=1), waits for the
ox-ui screen commit, QMP-screendumps, and **pixel-verifies the design
tokens at computed positions**: true-black surface at the bottom edge,
surface-high bar at 15 % height, primary accent line under the bar,
both sampled home-grid tiles (sample points chosen away from label
text), and wordmark pixels in the bar. Saves the PNG artifact
(/tmp/ox-uigate/ui-screendump.png).

## Debug journey

1. First pixel check sampled the *center* of a tile — which is where
   the component draws its label; a white text pixel tripped the
   assertion. Fixed by sampling right-of-text. (Lesson: pixel gates
   must reason about where TEXT lands, not just rects.)
2. Screendump races: the commit ack can beat the display flush, and
   the serial log raced the greps. Fix: every milestone is a bounded
   wait loop, and the gate retries capture+verify up to 3 attempts
   (the QMP screendump re-runs inside the retry loop).

## Honest limits

- Flat geometry only; no animations yet (motion spec is a later
  chunk, compositor-driven springs per the design language).
- Fixed curated palette; tonal-ramp generation from a user seed is a
  later token feature.
- No input handling in the toolkit yet (tiles are drawable, not
  tappable — input routing to app tiles comes with the shell chunk).
