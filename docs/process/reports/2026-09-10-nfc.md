# NFC: reader mode — chunk 43, Phase 4, 2026-09-10

## Claim

Ox OS reads NFC tags end to end on a VIRTUAL reader, through the
honest-permission contract. A host-side emulator (third member of
the modem-slot family: virtio-serial port named `oxnfc.0`, chardev
server=off + reconnect, port found via /sys/class/virtio-ports NAME)
emits idle frames while no tag is in range — the daemon's honest
no-tag leg — and, gated through a control socket, presents a tag as
a checksummed frame ($TGC,<uid>,<base64 text>*XX — NMEA framing with
an XOR checksum, so a corrupted frame can never become a tag read).
The new ox-nfcd daemon owns the port, verifies the checksum, decodes
the payload, journals the read verbatim, persists the tag atomically
to /data/ox/nfc-last.json, and serves `last {app}` behind permstored
`nfc.read`: deny refused, fake = a clearly synthetic tag (real text
asserted NOT to leak), grant = the real tag verbatim. The gate
proves the whole chain: reader owned -> no-tag -> tag presented ->
read+persisted -> matrix over the REAL tag.

## Stack layers (all gated)

1. **Reader (emulator)**: nfc-emu.py — idle `$TGN,*XX` frames every
   2 s (validated checksum, too), `--ctl` control socket for
   `present_tag` (uid must be 4..=20 hex, text 1..=120 printable
   ASCII; refused otherwise), one `$TGC` frame per presentation.
2. **Daemon** (ox-nfcd, new crate): find_port by sysfs NAME;
   frame_checksum_ok (XOR, same discipline as NMEA — unit-tested
   incl. corrupt frames); hand-rolled base64 decoder (padding
   handling unit-tested — the first draft rejected '=' inside val()
   and the round-trip test caught it before any boot); uid hex
   validation; text printable-ASCII validation; atomic
   tmp+rename persistence; journals `nfcd-ready transport=…`,
   `nfc-no-tag` (once, from the reader's idle frames),
   `nfc-tag-read uid=… text=…`, `nfc-tag-persisted`; IPC `last`
   consults permstored `nfc.read` with the consult journaled per
   mode (same pattern as camerad: driver store write is
   permission-free, the IPC surface is the policy point); `status`
   is the permission-free liveness probe (no payload leaves).
3. **Selftest** (nfc-selftest, new): waits for the idle leg, then
   for the gate's tag, then walks deny (`nfc-denied-refused`), fake
   (`nfc-fake-synthetic`, with an explicit no-leak check on the
   real text), grant (`nfc-real-tag-ok`: uid + text verbatim,
   synthetic:false), restores deny.
4. **Verification**: nfc-gate ALL GREEN (RC=0, first run):
   `nfcd-ready transport=/dev/vport4p1` -> `nfc-no-tag` ->
   TAG-PRESENTED -> `nfc-tag-read uid=04a2b3c4d5e6 text=boarding
   pass VF-2381 gate four` -> `nfc-tag-persisted` -> matrix
   milestones; the granted response carries exactly
   `{source:"nfc", text:"boarding pass VF-2381 gate four",
   uid:"04a2b3c4d5e6"}` with synthetic:false; zero stray QEMU.

## Instructive findings

1. **Padding is data to a hand-rolled base64 decoder.** The first
   draft's symbol table rejected '=' — so every padded input
   (i.e., every real text) failed decoding while the checksum and
   framing tests passed. The round-trip unit test with a padded
   vector caught it before any boot. Property to keep: decode must
   be tested against the ENCODER's real output, not just
   hand-typed strings.
2. **The chunk-38 rootfs bin-loop edit never landed** — the python
   edit script that added ox-sms to /usr/bin asserted on a bad
   anchor and died after only the first replacement; the chunk's
   gates still passed because Messaging launches from its package
   dir, not /usr/bin. Discovered now because nfcd (a DAEMON run by
   s6 from /usr/bin) genuinely needed the loop. Lesson: a failed
   multi-part edit must be re-audited part by part, not assumed
   whole.
3. **The no-tag leg is the reader's job.** Like gnss-no-fix, the
   honest empty state comes from the DEVICE (idle frames), not from
   a daemon timer — so "no tag" and "reader missing" stay
   distinguishable (no frames at all vs idle frames), and the
   selftest can require the idle leg before any tag exists.
4. **Driver-store writes stay permission-free; the IPC surface is
   the policy point.** The tag is persisted no matter what any app
   may later see — matching camerad (captures land in /data/ox/DCIM
   regardless) — because the privacy boundary is APP ACCESS to the
   payload, not the device knowing what its reader read.

## Honest scope

- Read-only reader: no card emulation (the phone as a tag), no
  peer-to-peer, no NDEF record structure (the payload is one text
  record), no reader-field control, no secure element.
- One tag slot: `last` serves the most recent read; a read history
  is a store/UI pass.
- The uid is whatever the reader reports — no collision/anti-
  cascade handling, no MIFARE/auth sectors.
- No UI app yet (the tag lands in the daemon store + journal); a
  reader app as a signed package would follow the Dialer pattern.
