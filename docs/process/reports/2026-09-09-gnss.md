# GNSS bring-up — chunk 34, Phase 4, 2026-09-09

## Claim

Ox's location stack is now REAL end to end on the virtual target: a
host-side NMEA emulator feeds a virtio-serial receiver port
("oxgnss.0"); ox-gnssd owns the port, validates and parses the NMEA
stream, and publishes the last-known fix to /data/ox/location.json —
and ox-locationd serves that exact fix to a GRANTED app through its
permstored gate (deny/fake/grant). The honest-permission contract
closed its last gap: grant mode used to answer "no fix" (honest, but
empty); it now answers with the receiver's actual position —
synthetic:false, source:gnss — while the fabricated coordinate stays
exactly where it belongs, in fake mode only.

## Stack layers (all gated)

1. **Receiver** (`tools/gnss-emu.py`): unix-socket NMEA emulator
   (QEMU chardev `server=off,reconnect=3`, same transport shape as
   the AT modem slot). Emits 1 Hz GGA with fix quality 0 and empty
   coordinates for the first 120 s after the guest connects, then
   GGA fix + RMC valid at a fixed position (37.774933, -122.419416,
   9 sats) so gate assertions compare exactly.
2. **Driver** (`ox-gnssd`, std-only Rust, 7 unit tests in EVERY
   payload build): finds the port via /sys/class/virtio-ports name
   (no udev, no hardcoded vport index), blocks on the stream, rejects
   every line failing the NMEA XOR checksum, parses GGA (fix
   authority) + RMC, converts ddmm.mmmm + hemisphere to signed
   degrees, journals the honest no-fix leg, persists the fix
   atomically (temp+rename) on first appearance and on movement.
   Receiver-less boots stay up serving "no fix" (oxmodemd's no-flap
   rule). NO permission check here on purpose: gnssd is the driver
   layer, locationd is the policy layer.
3. **Policy**: unchanged ox-locationd — its grant mode already read
   /data/ox/location.json ("written by the GNSS stack when a fix
   exists"); this chunk built the writer.
4. **Selftest** (s6 longrun `gnss-selftest`): grants gnss.test via
   permstored, polls locationd `fix` through the no-fix phase until
   the real fix flows, journals `gnss-location-grant-ok lat=… lon=…`,
   restores deny (least privilege).
5. **Verification** (`tools/gnss-gate.sh` ALL GREEN): receiver owned
   (`gnssd-ready transport=/dev/vport4p1`) → honest `gnss-no-fix` →
   `gnss-fix lat=37.77493 lon=-122.41942 sats=9` (coordinates
   assert-matched to the emulator within 0.002°) → granted app served
   `gnss-location-grant-ok lat=37.7749333… lon=-122.4194166…` — the
   served fix equals the receiver's fix and carries
   `synthetic:false, source:gnss, accuracy_m:5`.

## Instructive findings

1. **The driver/policy split is what makes the honest-permission
   story cheap.** ox-gnssd never asks who is asking; locationd never
   talks to hardware. Adding a real fix source changed ZERO lines in
   the permission layer — the file contract ("the GNSS stack writes
   location.json") was designed in the fake-providers chunk and just
   got its writer.
2. **A real fix is provably real only by coordinate identity.** Shape
   alone can't distinguish it from a synthetic one — the gate
   therefore asserts the served coordinates MATCH THE EMULATOR's
   configured position, which nothing on the guest could fabricate.
3. **workspace-test caught two bugs before any guest boot**: a
   `std::io::Write::writeln!` path that doesn't exist (macro needs
   the trait imported) and a test checksum helper formatting single
   hex digits ("5" not "05"), which failed 4 tests. Both died in the
   sandbox in ~2 minutes instead of in boot cycles.
4. **`set -u` makes heredoc argument mistakes fatal in gates**: the
   coordinate-check helper passed "$3" to python but was called with
   two arguments — bash refused to expand it and the gate died AFTER
   the guest had already gone green. Fixed by dropping the unused
   parameter (the tolerance lives in the python).
5. The NMEA no-fix phase counts from the guest's CONNECT, not
   emulator start, so the daemon reliably observes the honest no-fix
   state regardless of how fast the host boots relative to the VM.

## What this unlocks

- Location as a finished vertical: grants UI (already shipped) now
  toggles a fix source that actually exists; a Maps-style app is
  unblocked (tile/routing work is Phase 8).
- Camera geotagging when the camera HAL lands.
- On hardware: swap the emulator for a real GNSS module over UART —
  ox-gnssd's parser and the permission layer are unchanged; the gate
  becomes the hardware bring-up checklist.
